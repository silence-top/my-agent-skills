# Anti-Slop Review: does this look like an AI template?

After creating or restructuring a layout, review the whole composition once. Answer Yes / No / Not applicable for each item. When an item hits, change structure and information allocation rather than only changing colors. Card counts, metadata labels, and automated scores cannot replace visual judgment.

## 1. Eleven questions

- [ ] **Is the visual language generic?** After removing brand and accent colors, does the page still have clear hierarchy? Could another business name be substituted without changing the design?
- [ ] **Is every section a card?** Does the page fill with equal-weight icon + title + two muted lines cards? Are cards nested inside cards?
- [ ] **Are rounded rectangles unnecessary?** Do radius, stroke, or fill appear where there is no grouping reason?
- [ ] **Is glass overused?** Are gradients, glow, or glass present without a task reason? Is glass stacked on glass? Can the text background be computed? See [liquid glass](../materials/liquid-glass.md) §5.
- [ ] **Does spacing create hierarchy?** Is inter-group spacing larger than intra-group spacing, or is everything equally spaced? See [depth](../visual-dna/depth.md) §2.
- [ ] **Was mobile intentionally designed?** Was content reorganized by retain, summarize, drill down, and defer, or merely reduced from desktop? See [mobile](../platforms/mobile.md).
- [ ] **Does desktop feel like a real application?** Are window behavior, title bar, context menus, shortcuts, and drag-and-drop implemented, or is this a website in a window? See [native review](native-review.md).
- [ ] **Does interaction mean something?** Does every clickable element produce a real result and state feedback? Does each hover or motion explain something?
- [ ] **Does typography carry hierarchy?** Do size, weight, and line length establish priority, or do containers and dividers do all the work? See [typography](../visual-dna/typography.md).
- [ ] **Are shadows overused?** Are shadows reserved for true floating layers? Do they become floating black blocks in dark theme?
- [ ] **Does the whole product look AI-generated?** Does it resemble this business's tool or a sample that fits any project? Count hits such as purple gradients, glowing buttons, a three-card hero, or centered large heading + subtitle + two buttons.

## 2. Compare Avoid and Prefer

| Avoid hit | Prefer direction |
|---|---|
| generic SaaS / generic dashboard | Anchor the primary task before the shell; organize by business objects |
| excessive cards | Spatial hierarchy: spacing and alignment before containers |
| excessive gradients | Intentional contrast: one emphasis area, quiet surroundings |
| purple AI aesthetic | Restrained color derived from business and brand |
| random glassmorphism | Controlled transparency with an information and spatial reason |
| equal-weight stacking | Contextual surfaces: Canvas / Surface / Elevated have distinct roles |
| decorative motion | Restrained motion that explains state, hierarchy, or feedback |

See [premium UI](../visual-dna/premium-ui.md) §1 for the complete comparison and [anti-generic](../visual-dna/anti-generic.md) for symptom-by-symptom replacements.

## 3. Do not use mechanical template counts

Do not turn “four consecutive repetitions” into a context-free ban. Tables, media queues, and comparable metrics need consistent structures. The real defects are a missing primary task, equal weighting everywhere, gray canvas filled with white cards, and excessive decorative boundaries. If a new or revised layout still looks templated, change structure and information allocation rather than only color values.

## 4. Delivery decision

Use [visual review](visual-review.md) to check correctness and usability affected by the change; do not create a duplicate checklist. Global theme changes cover every supported theme, while a local fix does not rerun unrelated scenarios. No before/after report is required, and personality naming or recoloring does not prove the design works.
