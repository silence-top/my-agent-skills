# Solid：实色是默认材质

材质回答“内容浮在什么之上”。它是层级工具，不是风格配额；局部修复沿用现有材质，不为换材质而换。四种材质族按“可读性代价”递增：实色 → [半透明](translucent.md) → [磨砂](frosted.md) → [液态玻璃](liquid-glass.md)。

## 1. 什么时候用

默认选择。正文、表格、表单，以及一切高风险信息：用药剂量、金额、删除确认、权限说明、告警。底座检索出任何风格，这些位置都不改材质。

## 2. 构成

语义背景令牌（`--ui-canvas` / `--ui-surface` / `--ui-surface-elevated`）+ 必要描边或阴影。表面角色的分工见 [depth](../visual-dna/depth.md) §1。

```css
.solid-panel {
  background: var(--ui-surface);
  border: var(--ui-border-width) solid var(--ui-stroke);
}
.solid-floating {
  background: var(--ui-surface-floating);
  box-shadow: var(--ui-shadow-lg);   /* 阴影只给真实浮层 */
}
```

## 3. 什么时候不用

- 无任务理由的“高级感”替换：把可读的实色表单换成玻璃，只会降低可读性。
- 反过来也成立：实色不等于灰底白卡。分组优先靠间距和对齐，不靠给每段内容套一个实色盒子。

## 4. 暗色主题

暗色下阴影弱化，实色层主要靠色调差与必要描边区分；不为所有表面加描边。明暗两套主题分别验证文字对比。

## 5. 快速判断

1. 这个面承载什么信息？高风险或密集正文 → 实色，到此结束。
2. 它是不是产品身份的一部分？不是 → 实色。
3. 只有回答“它是常驻浮层 / 媒体上下文 / 产品身份的一部分”时才继续看其他材质。
