# Mobile Review：移动端验收

配合 [visual-review](visual-review.md) 的通用项使用；本篇只列移动专项。规则出处见 [platforms/mobile](../platforms/mobile.md)，平台差异见 [ios](../platforms/ios.md)、[android](../platforms/android.md)。

## 1. 移动反模式

命中即改结构，不只调色值。

| 编号 | 症状 | 修复 |
|---|---|---|
| `M1` | 导航形式先于目的地决策 | 按一级任务决定底部标签 / 任务入口 / 下钻 |
| `M2` | 桌面缩小或所有列纵排 | 重新安排保留、摘要、下钻、延后 |
| `M3` | 弹窗套弹窗 | 页面步骤或单一模态 |
| `M4` | 命中区小或相互重叠 | HTML 48×48 CSS px，双向实测；原生 44pt / 48dp 按平台 |
| `M5` | 安全区 / 吸底遮挡内容 | `env()`、预留空间与实际设备确认 |
| `M6` | 破坏系统滚动与缩放 | 保留平台行为，不禁缩放 |
| `M7` | 用渐变数量代替视觉锚点 | 主任务、面积、比例和阅读路径 |
| `M8` | 装饰循环 / 全局按压缩放 | 仅给相关操作语义反馈 |
| `M9` | 只靠颜色区分状态 | 加文本或图标 |
| `M10` | 软键盘遮住输入 / 提交 | 可滚动工作区、`dvh`、真机测试 |
| `M11` | 多个同权主操作 | 当前任务只保留一个最强动作 |
| `M12` | 只靠触感表示结果 | 明确可见和可播报反馈 |

## 2. 验收项

| # | 检查 | 判据 |
|---|---|---|
| 1 | 目标设备 | 本次受影响的视口（至少 360×800、390×844 之一；430×932 若产品面向大屏手机）无溢出、主动作可达 |
| 2 | 触控 | HTML 命中区双向 ≥ 48 CSS px；伪元素扩展不与邻居重叠 |
| 3 | 安全区 | 顶部 / 底部 / 左右 `env()` 已处理；桌面模拟标注“模拟” |
| 4 | 软键盘 | 输入聚焦后输入与提交仍可达；body 未固定死高度 |
| 5 | 长文本与缩放 | 200% 缩放和长中文换行不遮住操作、不裁切 |
| 6 | 导航 | 下钻可返回且保留筛选与滚动；手势不是唯一入口；底部标签 ≤ 5 项且切换实际内容 |
| 7 | 模态 | Sheet / Dialog 隔离背景、Escape 关闭、焦点恢复；无层层弹窗；无残留滚动锁 |
| 8 | 状态 | 适用的 loading / empty / error / denied 真实展示并可恢复 |
| 9 | 真实结果 | 搜索 / 完成 / 删除后计数与视图一致，来自同一数据源 |
| 10 | 动效 | 按压 / Sheet / 选中有语义时长；reduced-motion 与 motion=off 去位移 |
| 11 | 信息取舍 | 新布局回看：是否过度省略必要字段；主动作是否在拇指可达处 |
| 12 | 性能 | 图片有尺寸；长列表分页 / 虚拟化；LCP / INP / CLS 未测量不宣称达标 |

## 3. 测试方式必须注明

| 项 | 浏览器能测 | 只有真机 / 模拟器能测 |
|---|---|---|
| 布局、溢出、命中区尺寸 | ✓ | |
| 安全区实际值 | 模拟 padding | ✓ |
| 软键盘遮挡 | 缩短视口只是压力测试 | ✓ |
| 系统返回、手势返回 | | ✓ |
| Dynamic Type / 系统字号缩放 | 近似 | ✓ |
| VoiceOver / TalkBack | | ✓ |
| Haptic | | ✓ |

未做真机测试就说明边界；不把所有视口与状态组合重复作为日常任务要求。仓库示例的既有矩阵由预览工具维护。
