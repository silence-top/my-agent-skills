# Visual Review：交付前的正确性与视觉回看

统一交付清单。按本次变更选择相关项，不把所有项都变成全量验收；不适用不等于已验证。专项 review 解释方法，不要求重复填写报告。

## 1. 检查范围

| 变更 | 最少验证 |
|---|---|
| 文案、排版、样式 | 受影响区域的可读性、长文本、窄屏与现有主题；确认相邻布局未破坏 |
| 按钮、表单、弹层 | 真实操作、成功 / 失败、输入保留、键盘与焦点；覆盖本次涉及的状态 |
| 新页、布局重构 | 主任务闭环、主次结构、适用状态、目标设备布局与页面已有能力 |
| 全局主题或共享组件 | 扩展到实际使用它的代表页面；不能只检查一处 |
| 仓库示例与预览工具 | 重建预览并运行对应回归；不要求普通项目使用本仓库脚本 |

## 2. 正确性与可用性

编号保留便于源码扫描与问题定位，不要求交付时逐条抄写。

| 编号 | 检查 |
|---|---|
| `R01` | 分组有信息理由；优先内容、对齐与间距，不添加重复容器噪声 |
| `R02` | 颜色和共享尺寸来自项目正式 tokens；不引用不存在的 token，局部变量显式声明 |
| `R03` | 背景表达 Canvas / Surface 等语义，不随意复制灰色值 |
| `R04` | 组件服从产品结构与既有约定，不为改造而破坏合理默认行为 |
| `R05` | 控件具备适用的 idle / hover / active / focus-visible / disabled 状态；操作有真实结果 |
| `R06` | 字体回退可用，中西混排和数字可扫描；离线可用系统字体 |
| `R07` | 中文正文不负字距，正文和辅助标签可读，不以缩小字号制造密度 |
| `R08` | 动效解释状态、层级或反馈，无装饰循环和全局缩放 |
| `R09` | 实际需要的 loading / empty / error / denied 状态可恢复；不为本地工具伪造网络或权限态 |
| `R10` | 状态不只靠颜色，同时有文字、图标或其他可辨信息 |
| `R11` | 功能图标可辨且有可访问名称，不用模糊 Emoji 替代 |
| `R12` | 文案说明动作、结果和限制，不假成功、不伪造实时或 AI 诊断 |
| `R13` | 示例和模拟数据明确标注，不包含真实患者资料 |
| `R14` | 焦点可见；模态隔离背景、Tab / Shift+Tab 循环、Escape 关闭并恢复焦点 |
| `R15` | 支持系统 reduced-motion；若有页面动效开关，关闭后行为仍正确 |

数值底线：普通文字对比度 ≥ 4.5:1，大字 ≥ 3:1，不确定的媒体 / 渐变背景单列，不算自动通过；HTML 移动目标默认 48×48 CSS px，桌面 ≥ 24×24 CSS px；原生 iOS 44pt、Android 48dp 分别验收；Web 正文常用 14–16px，移动正文与输入默认从 16px 起。详见 [accessibility-review](accessibility-review.md)。

检查真实结果：搜索 / 清除恢复，完成 / 删除后计数与列表一致；表单校验、提交防重、失败保留输入；危险操作说明后果并确认或允许可靠撤销。只检查 class、属性或固定等待时间不能证明操作成功。

## 3. 视觉回看（新建或布局调整时）

逐项检查 Typography、Scale、Composition、Density、Surface、Contrast、Border、Illustration、Iconography、Motion、Image treatment、Navigation、Feedback，只回答与本次相关的维度：

- 第一眼能否识别主任务、主要内容和操作？导航与介绍没有盖过工作区？
- 去掉强调色后层级是否存在？锚点是否被导航或控制台遮挡？移动端是否需要换锚点？
- 标题、正文、证据有主次；相等权重来自可比关系，不是为了填满卡片。
- 移动端保留必要摘要和可达动作，不直接堆叠桌面；长文本与缩放不遮住操作。
- 字体、表面、尺度与反馈符合内容；是否落入 [premium-ui](../visual-dna/premium-ui.md) 的 Avoid 清单？整体模板感逐条对照 [anti-slop-review](anti-slop-review.md)。
- 无图片、无插图或无动画可以是经过说明的决定，而不是缺陷。

发现模板化就改信息组织或结构，不靠换色或写人格标签证明设计成立。无需强制第二轮报告；没有问题时不为凑次数改动。视觉判断不能由卡片计数、元数据标签或自动分数替代。

## 4. 简短交付

说明改了什么、如何验证、哪些未测；有可交互 HTML 时提供入口。无需另建报告文件或完整设计档案。

自动检查只证明实际测到的工程事实；失败、缺测、超时与 pending 均不得报通过。真机安全区、软键盘、原生集成与真实服务未测试时明确说明，不用浏览器模拟冒充。
