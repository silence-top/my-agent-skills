# Native Review：像真实应用，还是窗口里的网站

配合 [visual-review](visual-review.md) 使用。适用于 Electron / Tauri 桌面外壳与 iOS / Android 原生或跨端实现。原生感由真实系统集成行为证明，不由皮肤证明；规则出处见 [platforms/electron](../platforms/electron.md)、[macos](../platforms/macos.md)、[windows](../platforms/windows.md)、[ios](../platforms/ios.md)、[android](../platforms/android.md)。

## 1. 桌面外壳清单

逐项回答“是 / 否 / 不适用 / 未测”；“否”即改，“未测”写进交付说明。

| # | 检查 | 判据 |
|---|---|---|
| 1 | 窗口 | 有最小尺寸；记住位置与大小；缩放时布局重排而非等比缩放 |
| 2 | 标题栏 | 系统或自定义二选一明确；自定义时有可拖拽区域，控制按钮位置符合平台（macOS 左、Windows 右） |
| 3 | 侧栏 | 可收起 / 拖宽，状态持久化；选中样式符合平台（macOS 圆角块、Windows 左色条） |
| 4 | 工具栏 | 当前上下文高频动作；图标 + tooltip + 快捷键标注 |
| 5 | 右键菜单 | 核心对象有右键菜单，只放该对象相关动作；不弹浏览器默认菜单 |
| 6 | 快捷键 | 高频操作有平台惯例键；标注符号（macOS）/ 文字（Windows）正确；输入法组合态不拦截；有可搜索的快捷键面板 |
| 7 | 托盘 / 菜单栏 | 后台运行有意义时提供；关闭到托盘与退出区分明确 |
| 8 | 拖放 | 接受系统文件拖入，拖动中有目标态；应用内拖放有占位与取消 |
| 9 | 原生对话框 | 打开 / 保存用系统文件对话框；未实现的能力不放灰色按钮冒充 |
| 10 | 焦点 | 窗口失焦选中态按平台变灰；恢复后焦点回到原位；输入与播放状态符合预期 |
| 11 | 悬停 | 关键操作不 hover-only；触屏笔记本可用 |
| 12 | 选择 | 列表 Shift / Ctrl(Cmd) 多选、方向键、Enter、Delete；控件区文字不可选中 |
| 13 | 系统材质 | 用了 vibrancy / Mica / Acrylic 有系统关闭透明时的实色回退；高风险信息在实色面上 |
| 14 | 平台差异 | 同一产品结构一致，仅窗口控制位置、菜单、快捷键标注按平台调整 |

## 2. 移动原生清单

| # | 检查 | 判据 |
|---|---|---|
| 1 | 单位 | iOS 44pt / Android 48dp 按平台在原生实现中验收，不与 CSS px 混用 |
| 2 | 返回 | iOS 手势返回不是唯一入口；Android 系统返回逐层关闭正确 |
| 3 | 系统字号 | Dynamic Type / sp 缩放最大档位可换行不裁切 |
| 4 | 系统控件 | 导航栏、Tab 栏、Sheet、Alert 用系统控件或明确说明自绘理由 |
| 5 | 系统材质 | iOS 导航栏 / Tab 栏材质用系统能力；Android 默认实色 |
| 6 | 平台习惯 | 不混用：iOS 没有 FAB + 底部导航同时出现；Android 不照搬 iOS 返回箭头为唯一返回 |
| 7 | 读屏 | VoiceOver / TalkBack 焦点顺序与恢复正确 |
| 8 | 触感 | Haptic 仅补充，视觉与可播报反馈存在 |

## 3. 验收边界

| 能验证的环境 | 能证明 | 不能证明 |
|---|---|---|
| 浏览器预览 | 布局、键盘原则、焦点闭环、命中区尺寸 | 窗口、菜单、托盘、自动更新、系统剪贴板、原生文件权限、系统材质 |
| 打包后的桌面应用 | 上表全部桌面项 | — |
| iOS / Android 模拟器 | 系统返回、系统字号、系统控件外观 | 真机 Haptic、部分安全区实际值、性能 |
| 真机 | 全部 | — |

HTML 控件默认 48×48 CSS px；iOS 44pt 和 Android 48dp 分别在原生实现验收，不能当成 CSS px。安全区 `env()` 依赖设备，桌面浏览器模拟 padding 必须标注“模拟”。没有真机测试时不声称已验证键盘和底部手势条。

未做打包 / 真机验收时，交付说明写清哪些项“未测”，不把浏览器预览结果写成原生验收。视觉人格、节奏和高风险业务含义由用户在可交互产物中确认。
