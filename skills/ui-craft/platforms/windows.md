# Windows：效率、清晰边界、Ctrl 键

桌面外壳（Electron / Tauri）的通用原生感规则见 [electron](electron.md)；本篇只写 Windows 与 macOS 的差异。Windows 偏效率与清晰边界：区域之间用可见分界，控件有明确的矩形轮廓，密度可以更高。

## 1. 窗口与标题栏

- 窗口控制按钮（最小化 / 最大化 / 关闭）在右上角，宽度约 46px 一枚、高 32px 一排；自定义标题栏时用系统 overlay（`titleBarOverlay`）让系统绘制这组按钮，或严格复刻其位置与命中区。
- 标题栏整条可拖拽，控件区除外；双击标题栏最大化是系统预期。
- Snap 布局（悬停最大化按钮）由系统提供；自定义按钮会丢掉它，需要说明。
- 窗口最小尺寸按产品给出；布局随窗口比例重排，不等比缩放画布。

## 2. 边界与材质

- 区域之间用 1px 描边（`--ui-stroke`）或明确背景差表达，见 [materials/solid](../materials/solid.md)；不依赖大阴影。
- Mica / Acrylic 是可选系统材质：Mica 用于窗口底色透出壁纸，Acrylic 用于临时浮层（菜单、飞出）。用了要有回退（系统关闭透明效果时变实色）；不用也是正常选择。
- 侧栏选中项用左侧色条 + 底色，这是 Windows 习惯。
- 暗色模式跟随系统；高对比度主题（forced-colors）下描边必须仍可见。

## 3. 菜单与右键

- 应用菜单在窗口内（标题栏下方或汉堡按钮）；没有屏幕级菜单栏。
- 右键菜单是 Windows 用户的高频入口，覆盖当前对象的全部相关动作；`Shift+F10` 与菜单键等价打开。
- 设置用 `Ctrl+,` 或齿轮入口。

## 4. 快捷键

- 修饰键 `Ctrl`；标注用文字 `Ctrl+Shift+S`，不用符号。
- 遵守系统惯例：`Alt+F4` 关窗、`Ctrl+W` 关标签、`F2` 重命名、`F5` 刷新、`Ctrl+Z/Y` 撤销重做、`Alt` 激活菜单助记符。
- 不在输入法组合态拦截快捷键；提供可搜索的快捷键面板。

## 5. 字体与文字

系统字体 Segoe UI + Microsoft YaHei。雅黑在 12–13px 且 ClearType 关闭 / 缩放非整数时发虚，正文用 14px 起，辅助标签 12px 需实测；字重 500 在雅黑上可能回退到 400 或 700，用 400 / 600 两档。字体栈见 [typography](../visual-dna/typography.md) §1。

## 6. 系统集成

任务栏图标、跳转列表、系统通知（Toast）、系统文件对话框、资源管理器拖放、剪贴板、托盘图标——用了才提供，未实现不伪装。窗口失焦时标题栏与选中态变灰是系统预期。

## 7. 不做的事

- 把窗口控制按钮放左侧；用 macOS 的圆角选中块与 vibrancy 侧栏。
- 自制标题栏后丢掉 Snap 布局且不说明。
- 用 `⌘` 标注快捷键。
- 在浏览器预览里宣称验证了 Mica、Snap、任务栏集成；未打包验收就按 [native-review](../review/native-review.md) 说明边界。
