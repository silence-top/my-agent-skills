# macOS：沉浸、统一材质、键盘优先

桌面外壳（Electron / Tauri）的通用原生感规则见 [electron](electron.md)；本篇只写 macOS 与 Windows 的差异。macOS 偏沉浸与统一材质：窗口、侧栏、工具栏更像一块连续的材质，层级靠 vibrancy 与细描边而不是硬边框。

## 1. 窗口与标题栏

- 窗口控制按钮（关闭 / 最小化 / 缩放）在左上角。自定义标题栏时保留这组按钮的位置与尺寸，或使用系统 `titleBarStyle: hiddenInset` 类方案让系统绘制。
- 标题栏可与工具栏合并（unified toolbar）；合并后整条区域可拖拽，控件区除外。
- 全屏是系统行为（绿色按钮），不自制“全屏”按钮。
- 窗口最小尺寸按产品给出；布局随窗口比例重排，不等比缩放画布。

## 2. 侧栏与材质

- 侧栏使用系统 sidebar 材质（vibrancy），透出桌面壁纸色调；Web 实现是近似模拟，见 [materials/frosted](../materials/frosted.md)，不宣称等同。
- 侧栏选中项：圆角底色块 + 字重，不用左侧色条（那是 Windows / Web 习惯）。
- 主工作区与检查器用实色面，材质只在外壳层。高风险信息永远在实色面上。
- 暗色模式跟随系统外观；阴影在暗色下弱化，靠描边区分层。

## 3. 菜单栏与右键

- 应用菜单栏（屏幕顶部）是核心操作的完整入口：文件、编辑、视图、窗口、帮助结构；每个菜单项有快捷键标注。
- 右键菜单只放当前对象相关的动作，不复制整个工具栏。
- 首选项 / 设置用 `Cmd+,`，位于应用菜单下。

## 4. 快捷键

- 修饰键 `Cmd`；标注用符号 `⌘ ⇧ ⌥ ⌃`，顺序 `⌃⌥⇧⌘`。
- 遵守系统惯例：`Cmd+W` 关窗、`Cmd+Q` 退出、`Cmd+,` 设置、`Cmd+F` 查找、`Cmd+Z/⇧Z` 撤销重做。
- 不在输入法组合态拦截快捷键；提供可搜索的快捷键面板。

## 5. 字体与文字

系统字体 SF Pro + PingFang SC；正文 13px 是 macOS 原生控件的常见字号，长阅读区 14–16px。字体栈见 [typography](../visual-dna/typography.md) §1。

## 6. 系统集成

菜单栏图标（NSStatusItem）、Dock 角标、通知中心、系统文件对话框、Finder 拖放、剪贴板——用了才提供，未实现不伪装。窗口失焦时选中态变灰是系统预期行为，不要强制保持高亮。

## 7. 不做的事

- 把窗口控制按钮放右侧；用 Windows 风格的硬边框卡片堆叠。
- 自制标题栏但没有可拖拽区域。
- 用 `Ctrl` 标注快捷键。
- 在浏览器预览里宣称验证了 vibrancy、菜单栏、全屏行为；未打包验收就按 [native-review](../review/native-review.md) 说明边界。
