# Web：业务系统与高频工作区

Web 的输入是鼠标、键盘、浏览器导航与多标签。结构决策：稳定 URL 与筛选、语义表格、明确的主工作区。不能照搬：原生窗口按钮、伪装的系统权限、占用浏览器保留快捷键。下列尺寸与骨架是中后台场景默认值（SHOULD），不是媒体、工具、专题页的万能模板；工程底线为 MUST。

## 1. 页面骨架

Workspace 只是候选之一，先与 List-first、Search-first 比较（见 [depth](../visual-dna/depth.md) §5）；不需要的顶栏、侧栏、页头、分页不必添加。

```
┌─ 顶栏：品牌 / 全局搜索 / 环境标识 / 用户 ──────────────┐
├─ 侧栏 ─┬─ 页头：标题 + 面包屑 + 主操作 ───────────────┤
│        │  筛选区（可折叠）                            │
│        │  工具栏：批量操作 / 列设置 / 密度 / 导出       │
│        │  内容区（表格 / 表单 / 看板）                 │
│        │  分页 / 吸底操作条                            │
└────────┴──────────────────────────────────────────┘
```

| 区域 | 尺寸 | 规则 |
|---|---|---|
| 顶栏 | 高 48–56px | 只放全局项，不放页面操作 |
| 侧栏 | 宽 200–240px（展开）/ 56–64px（折叠） | 层级 ≤ 3；超过换二级导航，不做四级缩进 |
| 内容区 | 左右内边距 16–24px | 数据工作区利用可用宽度；阅读与表单按任务限宽 |
| 页头 | 高 48–64px | 标题在左、主操作在右；主操作 ≤ 3 个，其余收进“更多” |
| 吸底操作条 | 高 56–64px | 长任务有价值时采用；预留滚动区域与安全区，不遮内容 |

响应式：设计基准 1280×800；1024 必须可用（侧栏自动折叠为带可访问名称的图标轨道或可打开面板，纯文字不能挤成竖排）。< 1024 重新判断任务：低频属性进详情、编辑分步，只有真实比较表格允许局部横向滚动。移动端只做真正需要的场景，不把 PC 页面缩小塞手机——移动结构见 [mobile](mobile.md)。视口验收矩阵见 [responsive-review](../review/responsive-review.md)。

## 2. 表格

| 密度 | 行高 | 字号 | 内边距 | 适用 |
|---|---|---|---|---|
| 紧凑 | 36px | 13px | 8px 12px | 对账、日志、批处理 |
| 默认 | 44px | 14px | 10px 16px | 大多数列表页 |
| 宽松 | 52px | 14px | 14px 16px | 含头像 / 多行副信息 |

高频表格提供密度切换并记住选择。行高是参考不是裁切上限；触控模式命中区仍 ≥ 48×48 CSS px。

列规则：
- 列宽语义化：ID 等宽固定；名称弹性最宽；状态 / 操作固定窄。
- 文本左对齐；数字与金额右对齐 + `tabular-nums`；状态列同一表格内一致。
- 表头吸顶 `position: sticky; top: 0`，层级用 `--ui-z-sticky`。首列固定时用 `box-shadow` 或 `border-right` 表达“固定层”。
- 操作列固定右侧，列内按钮 ≤ 3，其余收进“更多”；图标按钮必须有 `aria-label`。
- 选择列固定最左，宽 40–48px；表头全选支持三态。
- 默认单行省略；仅“必须看全”的列允许 2 行 `-webkit-line-clamp`。
- 排序：升序 → 降序 → 不排序，排序中有箭头 + 颜色指示。

| 状态 | 表现 |
|---|---|
| Loading | 骨架屏，行数与列宽匹配真实表格；不用一个居中转圈 |
| Empty（首次） | 说明这张表是什么 + 主行动按钮 |
| Empty（筛选后） | 说明当前筛选条件 + `清除筛选` |
| Error | 说明失败原因 + `重试`；保留表头，不整页白屏 |
| No permission | 说明缺少什么权限 + 申请路径；不显示空表格 |

分页：默认每页 20，可选 20 / 50 / 100；可信总数显示 `共 1,284 条`，否则显示已加载数；选中后显示 `已选 3 条`；页码超过 7 个用省略号折叠；大数据量用“加载更多”或虚拟滚动，并显示当前已加载条数。

## 3. 表单

| 项 | 规则 |
|---|---|
| 标签位置 | 默认顶部对齐；仅字段名都 ≤ 4 字且垂直空间紧张时左侧对齐 |
| 单列 / 双列 | 默认单列；字段成对（起止日期、省 / 市）才双列，且标签等长 |
| 分组 | > 8 个字段必须分组，组内有标题与分隔 |
| 控件宽度 | 按内容预期长度：姓名 160px、地址 100%（max 480px）、日期 160px；不全部 100% |
| 间距 | 标签与控件 8px；字段之间 16–20px；字段组之间 32px |

校验：失焦 + 提交，不每次按键报错；中文输入在 `compositionend` 之后（见 [typography](../visual-dna/typography.md) §5）。字段下方预留最少一行提示位，用 `min-height` 不用固定高度：

```css
.field__msg {
  min-height: calc(var(--ui-text-caption) * var(--ui-leading-snug));
  margin-top: var(--ui-space-1);
  font-size: var(--ui-text-caption);
  line-height: var(--ui-leading-snug);
  color: var(--ui-text-muted);
}
.field.is-error .field__msg { color: var(--ui-danger); }
```

横向筛选条用 `align-items: flex-end` 对齐时，出错字段变高会把整排顶乱；这种受控布局才允许提示绝对定位，并由容器预留空间（`.filter-bar { padding-bottom: var(--ui-space-6); }`），窄屏与长文本改回文档流。提示说清“哪里错、应该是什么”，值就在框里时不重复；不裁切错误信息。

- 必填用 `*`，全站统一位置，表单顶部说明。
- 提交失败：滚动并聚焦第一个错误字段，顶部给汇总。
- 只读场景优先 `readonly`（可复制、可聚焦、可提交）；`disabled` 不参与提交也不在 Tab 顺序。
- 危险操作二次确认，文案写出具体数量与对象。
- 长表单（> 15 字段或 > 1 屏）有草稿保存或离开确认；提交中禁用按钮 + 幂等键。

## 4. 详情页

描述列表（label + value），不用只读输入框拼装；分组与表单一致，组标题 14–16px / 600；长文本单独成块，行高 1.75，最大宽约 42em；关键字段可置顶摘要但不再套卡；时间线用“时间（等宽）+ 操作人 + 动作 + 结果”三段式。

## 5. 弹窗 / 抽屉 / 浮层

| 场景 | 用什么 |
|---|---|
| 必须做决定才能继续 | Modal |
| 保留上下文、边看边改 | Drawer，宽 480–720px |
| 轻量信息补充 | Popover / Tooltip |
| 长表单 | 不用弹窗，独立页面或全屏抽屉 |

- 弹窗宽度分级 `480 / 640 / 800 / 1000px`，不要任意宽度。
- 遮罩用项目遮罩色；blur 默认关闭，材质选择见 [materials/frosted](../materials/frosted.md)。
- 焦点锁定、`ESC` 关闭、点遮罩关闭（危险确认不允许）、关闭后焦点回到触发元素。
- 弹窗内不再开弹窗；确实需要改为弹窗内步骤切换。标题用动词短语。

## 6. 反馈分级

| 类型 | 用途 | 时长 |
|---|---|---|
| 内联提示 | 与当前字段相关 | 持续 |
| Toast | 操作结果，不需用户处理 | 2–3s（错误 4–5s） |
| Notification | 系统级、需用户知晓或处理 | 手动关闭 |
| Banner | 环境标识、只读模式、数据延迟 | 持续 |

字段级 → 内联；表单级 → 表单顶部；操作级 → Toast；系统级 → 通知。Toast 同屏 ≤ 3 条、可关闭、不遮主操作区；异步结果 `aria-live="polite"`。不为每次成功都弹窗。

## 7. 导航、权限与异常

- 层级 ≤ 3，超过用面包屑或页签；当前项用色条 + 底色 + 字重，不只改颜色；侧栏折叠状态持久化；页签用于同实体不同视图，不替代主菜单，> 8 个支持滚动。
- 无权限不是 404：说明缺什么权限 + 申请方式。登录过期回到原页面并保留查询条件。数据过期 / 离线顶部横幅说明并禁用不可靠操作。接口失败保留上一份数据并标注“可能不是最新”。

## 8. 键盘、命令与焦点

显式“命令”按钮与快捷键并行；`Command/Ctrl+K` 仅在业务确需且不处于输入法组合态时拦截；不覆盖刷新、后退、复制等浏览器语义。命令列表可搜索、方向键移动、Enter 执行、Escape 关闭并回到触发点。

Tab 顺序跟随阅读顺序，不用正 `tabindex` 修补 DOM。模态用原生 `dialog` 或等效 inert + 焦点循环；快速开关可中断，不留 inert、滚动锁或过渡态。列表删除后焦点到相邻条目或新建入口；筛选后不偷焦点到结果；数量变化用 `aria-live` 说明。低频危险操作进明确命名的菜单或确认，不与主执行键同权并列。

## 9. 未保存、文件与隐私

脏状态由真实数据变化产生，保存成功后再清除；路由守卫实际注册，浏览器退出用 `beforeunload` 并说明浏览器可能不显示自定义文案；恢复输入不等于已保存至服务器。本地工具标明文件仅在浏览器使用，Blob URL 及时释放；文件选择失败、不可解码、剪贴板拒绝分别给出恢复路径，不用成功 toast 掩盖。示例数据明确标注本地模拟。

## 10. 四类常被跳过的场景

| 场景 | 关键规则 |
|---|---|
| 多步向导 | 步骤 ≤ 5，动词短语命名；每步独立校验；后退保留内容且不触发校验；已完成步骤可跳回；> 3 步或 > 20 字段自动存草稿；提交失败定位到出错的那一步；顶部显示 `第 2 / 4 步` |
| 可编辑表格 | 显式点击“编辑”进入，不点单元格即变输入框；失焦校验，行首汇总错误数；行级保存优于整表；`Enter` 提交 / `Esc` 撤销 / `Tab` 下一格；默认不乐观更新；编辑态行数上限（如 200），超过改“导出 → 改 → 导入” |
| 树形结构 | 缩进 16–20px 一级，> 5 级换面包屑式下钻；默认展开到第 2 级并记住状态；三态复选框 + “仅选本级”；搜索自动展开命中路径并说明搜索范围；> 500 节点虚拟滚动；`role="tree"` / `treeitem` / `aria-expanded` / `aria-level` |
| 附件上传 | 选择前写清类型与大小上限；每个文件独立进度与状态；失败可重试；上传中可取消；预览失败给下载兜底；删除已上传附件二次确认；服务端必须再校验；拖拽区有键盘等价按钮 |

## 11. 自检

| # | 检查 | 判据 |
|---|---|---|
| 1 | 表格四态 | 声明支持的 loading / empty / error / no-permission 正确恢复 |
| 2 | 表格尺寸 | 有密度切换，行高来自令牌 |
| 3 | 数字列 | 右对齐 + `tabular-nums` |
| 4 | 表单标签 | 顶部对齐、必填标记统一、未用 placeholder 当标签 |
| 5 | 校验时机 | 失焦 + 提交；中文组合态后校验 |
| 6 | 危险操作 | 二次确认且说明数量与后果 |
| 7 | 弹窗 | 焦点锁定、ESC、遮罩策略、宽度来自分级 |
| 8 | 反馈分级 | 内联 / Toast / 通知 / 横幅使用正确 |
| 9 | 权限态 | 无权限有说明与申请路径，不用 404 冒充 |
| 10 | 向导 | 每步独立校验；提交失败能定位到出错步骤 |
| 11 | 可编辑表格 | 显式进入编辑；行级保存；未保存有拦截 |
| 12 | 树形结构 | 三态全选；搜索展开命中路径；> 500 节点虚拟滚动 |
| 13 | 附件上传 | 选择前告知限制；失败可重试；拖拽区键盘可达 |
| 14 | 字段提示位 | 预留最小提示空间；长错误与文字放大不裁切、不覆盖其他字段 |
| 15 | 键盘 | 命令入口有显式按钮；不覆盖浏览器保留快捷键；焦点闭环 |
