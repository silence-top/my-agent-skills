# Electron：外壳应用 ≠ 窗口里的网站

适用于 Electron / Tauri 等 Web 技术桌面外壳。决定“像不像原生桌面应用”的是窗口与系统集成行为，不是皮肤。平台差异见 [macos](macos.md)、[windows](windows.md)；Linux 以 Windows 规则为基准（控制按钮位置随桌面环境，用系统标题栏最稳）。同一产品保持结构一致，按平台调整窗口控制位置、菜单与快捷键标注。

## 1. 输入方式决定结构

桌面生产力应用的输入是键盘高频、长会话、多窗与大屏。结构决策：资源导航 / 主工作区 / 检查器三区、命令入口、可收起次区。不能照搬：手机底部标签承载所有工具、伪装原生系统权限、把 Web 页面直接套壳。

主工作区必须占主要可用面积；导航与检查器围绕它服务。次区可折叠时保留显式展开入口和焦点恢复；折叠不清空输入。给出产品最小窗口，不靠横向滚动掩盖问题。

## 2. 十三项原生感清单

| 项 | 原生感的判据 | 网站感的症状 |
|---|---|---|
| Window 窗口 | 有最小尺寸；记住上次位置与大小；多窗口有明确职责 | 固定单窗，缩小后横向滚动 |
| Titlebar 标题栏 | 明确选系统标题栏或自定义；自定义时有 `-webkit-app-region: drag` 区域与平台位置正确的控制按钮 | 顶部是网页导航栏，没有可拖拽区 |
| Sidebar 侧栏 | 可收起 / 可拖宽，状态持久化；选中样式跟平台 | 固定宽度导航菜单 |
| Toolbar 工具栏 | 放当前上下文的高频动作，有图标 + tooltip + 快捷键标注 | 一排等权按钮或没有工具栏 |
| Context Menu 右键菜单 | 核心对象有右键菜单，只放该对象相关动作 | 右键弹出浏览器默认菜单或无响应 |
| Keyboard Shortcut 快捷键 | 高频操作有平台惯例快捷键；不在输入法组合态拦截；有可搜索的快捷键面板 | 只有鼠标路径；`Ctrl+K` 在中文输入时被吞 |
| System Tray 托盘 / 菜单栏 | 后台运行有意义时提供；有关闭到托盘 vs 退出的明确区分 | 关窗即退出但声称“后台运行” |
| Drag & Drop 拖放 | 接受系统文件拖入，拖动中有明确目标态；应用内拖放有占位与取消 | 只能通过文件选择器 |
| Window Resize 窗口缩放 | 布局随窗口比例重排；三区在窄窗口下折叠而非挤压 | 等比缩放画布或元素重叠 |
| Native Dialog 原生对话框 | 打开 / 保存用系统文件对话框；危险确认可用系统对话框 | 自绘文件选择器 |
| Focus 焦点 | 窗口失焦时选中态按平台变灰；恢复焦点回到原位置；输入与播放状态符合预期 | 失焦后仍高亮，恢复后焦点丢失 |
| Hover 悬停 | hover 只做提示与轻反馈，关键操作不 hover-only；触屏笔记本可用 | 关键按钮只在 hover 出现 |
| Selection 选择 | 列表支持 Shift / Ctrl(Cmd) 多选、方向键移动、Enter 打开、Delete 删除；文本选择在正文区可用、在控件区禁用 | 只能单击单选；随处可选中 UI 文字 |

## 3. 系统集成：用了才提供

托盘、菜单栏、文件拖放、原生文件对话框、系统通知、剪贴板、自动更新、深链协议——每一项要么真实接线，要么不出现在界面上。未实现的能力不放灰色按钮冒充“即将上线”。

## 4. 键盘、命令与焦点

显式“命令”按钮与快捷键并行；命令面板可搜索、方向键移动、Enter 执行、Escape 关闭并回到触发点。Tab 顺序跟随阅读顺序；模态用原生 `dialog` 或等效 inert + 焦点循环；列表删除后焦点到相邻条目或新建入口。低频危险操作进明确命名的菜单或确认，不与主执行键同权并列。

## 5. 视口与缩放

| 窗口 | 结构 |
|---|---|
| 1920×1080 | 增加工作区面积，不把控件无限拉宽 |
| 1440×900、1280×800 | 主任务、队列、上下文并置 |
| 1024×768 | 检查器可收起，关键状态保留 |
| 768×1024 | 过渡布局，明确合并或下钻的区域 |

真正的二维数据表允许在有标签的局部容器滚动；窗口整体不横向溢出。200% 系统缩放下控件可换行，工作区切换为分步结构。

## 6. 未保存、文件与隐私

脏状态由真实数据变化产生，保存成功后再清除；关窗前拦截用系统对话框确认。本地文件路径、最近文件列表尊重系统隐私设置；Blob / 临时文件及时释放。文件不可解码、剪贴板拒绝、权限被拒分别给出恢复路径。

## 7. 材质

系统材质（macOS vibrancy、Windows Mica / Acrylic）能用就用平台能力，见 [materials/frosted](../materials/frosted.md)；Web 自绘是近似，要有系统关闭透明效果时的实色回退。高风险信息永远在 [实色](../materials/solid.md) 面上。

## 8. 验收边界

浏览器预览可以验证布局与键盘原则，不能声称验证了窗口、菜单、托盘、自动更新、系统剪贴板或原生文件权限。原生感由真实系统集成行为证明；未做打包验收时按 [native-review](../review/native-review.md) 说明边界。
