# Premium UI：什么算精致，什么一眼模板

本技能的审美立场，优先级高于任何风格检索结果（包括 UI/UX Pro Max 给出的风格与配色建议）。底座回答“这类产品常用什么”，这里回答“怎么做才精致”。

## 1. Avoid / Prefer

| Avoid（没有任务依据时） | Prefer |
|---|---|
| generic SaaS 外壳：侧栏 + 顶栏 + 卡片墙 | 空间层级：主任务占主要面积，次区退后 |
| generic dashboard：四张等权 KPI 卡 + 一张图 | 材质层级：实色承载内容，玻璃只做常驻浮层 |
| 到处等宽卡片、每个字段一个盒子 | 克制的透明度：透出的是真实下层内容，不是固定半透明色 |
| 渐变主视觉、渐变标题文字 | 细腻深度：阴影只给真实浮层，边界只在必要分界 |
| 紫色 AI 风、发光边框、呼吸光圈 | 有意图的对比：对比服务主次，不服务“高级感” |
| 随机玻璃拟态、满屏 blur | 随内容变化的表面：表面角色由承载的信息决定 |
| 装饰性动效：入场整屏、悬停上浮、循环漂浮 | 讲究的排版：字体角色、尺度、行高、中文标点承担层级 |
| 首屏 Hero 把工作区挤出屏幕 | 克制的动效：解释层级、叙事、反馈、状态，说不清就删 |

精致来自“去掉无效装饰后主次更清楚”，不是往上加东西。替换思路：把装饰换成信息——分隔用留白和对齐，强调用字重和字色，分组用真实的数据关系（时间、状态、归属）。

## 2. 视觉锚点

每页至少一个明确主锚点：当前任务、输入/输出工作区、关键图表、查询、时间轴、媒体、标题与证据的关系均可。一个主锚点可以包含紧密关联的对象，但不能把所有卡片都标成主锚点。

选择方法：主任务需要先看到什么 → 分配面积 / 位置 / 对比 → 组织视线路径 → 让次区退后。不强制 Hero、渐变、发光或大数字配额。没有媒体时，锚点指向可见的本地文件选择工作区，不指向隐藏播放器。

人工检查：第一眼能否识别主任务？去掉强调色后层级是否存在？锚点是否被导航 / 控制台遮挡？移动端是否需要换锚点？

## 3. 人格词汇（组合用，不要求命名）

人格通过结构与行为实现，不是主题、行业标签或配色开关。最多一个主导人格与一个辅助人格，辅助只影响明确的局部角色。浅色与暗色保持同一结构身份。

| 人格 | 排版与尺度 | 构图、密度与表面 | 边界与禁用组合 |
|---|---|---|---|
| Technical | 工具信息等宽；正文保持阅读字体 | 工作区、命令、列表；高频区紧凑；平面内容优先，精确选中对比 | 不把所有正文等宽化 |
| Premium | 少量展示字 + 清晰正文；用比例而非极细字制造精致 | 主次不对称；少量表面；边框仅定义必要分界 | 禁止把 blur、金色或大留白当定义；高风险任务不低对比 |
| Editorial | 标题、摘要、正文、旁注分工；可选本地衬线标题 | 论点 → 证据 → 解释；排版和留白分组；分隔线表达章节 | 不用于反复横向对照的密集编辑器 |
| Calm | 稳定字重、舒适行高 | 主任务明确，逐步披露；柔和背景但文字合格 | Calm ≠ 灰到看不清 |
| Futuristic | 精确数字 + 现代正文 | 实时信号为锚点；功能性发光仅用于选中或告警 | 禁止伪造实时数据、扫描线装饰、AI 置信度 |
| Organic | 自然阅读节奏；中文不负字距 | 按内容关系流动分组；形状表达关系；表面少 | 不把每容器做不规则形 |
| Playful | 一个有趣的展示角色，正文稳定 | 趣味放在低风险发现与完成反馈；高对比强调点 | 禁止危险操作、付款确认中的玩笑反馈 |
| Cinematic | 标题简短有张力；媒体与字幕主次清楚 | 媒体主导、队列从属；控件放确定背景 | 不用假封面和假播放；不牺牲字幕与控制对比 |
| Industrial | 主键、状态、数值精确 | 列表与流程优先；高密度但分组鲜明；坚实平面 | 不等于全部加粗和粗边框 |
| Human-centered | 任务语言先于系统术语 | 当前人 / 任务 → 下一步 → 证据；风险分层；无需处处卡片 | 不伪造患者、医生或推荐结果 |

组合示例：医疗工作台 = Technical 主导队列与键盘 + Human-centered 负责核对语言；媒体 = Cinematic 主导主体 + Editorial 负责标题与队列排版；专题展示 = Editorial 主导论点 + Premium 负责比例与排版。

不提供“任意人格套任意构图”的运行时开关。人格靠结构和行为实现；主题开关只改语义色值。

## 4. 与底座的关系

- 底座检索到的风格（如 Glassmorphism、Dark、Minimal）是候选，不是决定；先过 §1 的 Avoid 列表再采用。
- 底座给出的配色与字体组合经 [typography](typography.md) 的中文规则和 [accessibility-review](../review/accessibility-review.md) 的对比度实测后使用。
- 材质选择见 [materials/](../materials/solid.md)；表面、节奏与构图见 [depth](depth.md)；整体是否像模板见 [anti-slop-review](../review/anti-slop-review.md)。
